# Language Processor

Development of a language processor in Java, implementing the main stages of language analysis.

## Features
- Lexical analysis and token generation.
- Character classification and transition matrices.
- Recursive descent syntactic analysis.
- LL(1) grammar processing.
- Semantic analysis and type checking.
- Symbol table management.
- Function declaration and parameter validation.
- Compilation error detection and management.

## Technologies
- Java
- Object-Oriented Programming
- Compiler Design
- Lexical Analysis
- Parsing
- Semantic Analysis
- Data Structures

## Project Structure
- `lexico/`: Lexical analyzer.
- `matriz_transiciones/`: Character classification and transition management.
- `sintactico/`: Grammar and syntactic analyzer.
- `semantico/`: Semantic analysis and type compatibility.
- `tabla_simbolos/`: Symbol table implementation.
- `gestor_errores/`: Error management.
- `procesador/`: Main application.
